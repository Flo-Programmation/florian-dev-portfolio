API REST - ToDo List

Création d'une application capable de gérer dynamiquement des tâches grâce à des requêtes HTTP, développée avec Python et FastAPI.

Langages & Techs
Python FastAPI SQL JSON Uvicorn
Date Mai - Juin 2026
Contexte Stage CIREST, Saint-Benoît

À propos du projet

Durant mon stage à la CIREST, j'ai eu pour mission de concevoir une API REST robuste permettant de gérer une application de type ToDo List. L'objectif était de me familiariser avec le développement Back-End en utilisant Python et FastAPI, tout en structurant les échanges de données au format JSON.

Fonctionnalités développées :

  • Opérations CRUD : Création, modification, suppression et affichage de toutes les tâches.
  • Gestion du temps : Ajout d'une date de fin pour chaque tâche.
  • Système d'alerte : Déclenchement d'une alerte lorsqu'une tâche arrive à moins de 24 heures de sa date limite.
  • Traitement par lots : Possibilité de supprimer plusieurs tâches simultanément.

Défis techniques surmontés :

La principale difficulté de ce projet a résidé dans la gestion des dates et du temps, ainsi que dans la validation stricte des données envoyées à l'API. La résolution de ces problématiques m'a permis de mieux appréhender les exigences de sécurité et de fiabilité côté serveur.
